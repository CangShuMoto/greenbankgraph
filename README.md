# Greenbank Radioastonomy Graph Project
## Summary
Greenbank currently has an issue. One of their bits of equipment has gone down! It is some form of dot matrix-ish graph printer.
## Design Considerations

### Analog vs Digital?
There will be 2 primary concerns to convert from analog to digital.
1. Signal Resolution
2. Voltage Scale

For Signal Resolution, it is theoretically infinite, but practically the graph is only divided into so many units.

Minimum desired resolution will be the same as the smallest subdivision of the existing graph.

Ideally it will be greater than that.
